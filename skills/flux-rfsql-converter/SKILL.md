# FLUX RF 端 SQL 转换器

将标准 Oracle SQL 转换为 FLUX 系统 RF 端低代码平台兼容的 SQL 格式。

FLUX RF 端有一套专属的 SQL 语法，用于将查询结果绑定到前端控件、引用系统常量和用户输入参数。本 Skill 将原始 SQL 逐条规则转换为该平台可识别的格式。

---

## 转换流程

收到用户的 SQL 后，按以下顺序逐步转换。每一步完成后自检，确保没有遗漏。

### 步骤 1：SELECT 别名转换

**规则 A — 已有别名的列**：将列别名用 `@` 包裹。

```
转换前：ILLI.LOCATIONID AS HIDE_LOCATIONID_1
转换后：ILLI.LOCATIONID AS @HIDE_LOCATIONID_1@

转换前：BS.SKUDESCR1    AS LBL_SKUDESCR_1
转换后：BS.SKUDESCR1    AS @LBL_SKUDESCR_1@
```

**规则 B — 所有列都无别名**：给每列添加 `AS @LIST_VIEW@`。

```
转换前：SELECT BZ.ZONEGROUPDESCR, US.KEEPER, US.SHOWSEQUENCE
转换后：SELECT BZ.ZONEGROUPDESCR AS @LIST_VIEW@,
              US.KEEPER         AS @LIST_VIEW@,
              US.SHOWSEQUENCE   AS @LIST_VIEW@
```

**规则 C — 仅个别列无别名**：不做处理，保持原样。

### 步骤 2：删除 ORGANIZATIONID

FLUX RF 端通过 `#ORGANIZATIONID#` 系统常量自动注入组织 ID，SQL 中不应出现硬编码的 ORGANIZATIONID 条件。

**WHERE 条件中**：删除所有 `table.ORGANIZATIONID = 'XX'` 条件（含前面的 `AND`）。

```
转换前：WHERE ILLI.ORGANIZATIONID = 'ND'
            AND ILA.LOTATT08 = 'Y'
转换后：WHERE ILA.LOTATT08 = 'Y'
```

**JOIN 条件中**：删除 `table1.ORGANIZATIONID = table2.ORGANIZATIONID AND` 片段。

```
转换前：ON BS.ORGANIZATIONID = ILLI.ORGANIZATIONID AND BS.CUSTOMERID = ILLI.CUSTOMERID
转换后：ON BS.CUSTOMERID = ILLI.CUSTOMERID
```

> 注意：删除后要检查 `AND` / `ON` 的衔接，确保没有多余的 `AND` 或语法断裂。

### 步骤 3：系统常量替换

将硬编码的系统字段值替换为 FLUX 系统常量：

| 硬编码值示例          | 替换为                  |
| --------------------- | ----------------------- |
| `WAREHOUSEID = 'NDCZ'` | `WAREHOUSEID = '#WAREHOUSEID#'` |
| `LANGUAGEID = 'zh_CN'` | `LANGUAGEID = '#LANGUAGE#'`     |
| `USERID = 'xxx'`       | `USERID = '#USERID#'`           |

> `ORGANIZATIONID` 的值替换已在步骤 2 中通过删除处理。如果某处 ORGANIZATIONID 未被删除（如出现在 SELECT 或 GROUP BY 中不需要删除），则其值不替换。

### 步骤 4：注释转换（WHERE 条件中的控件 ID）

检查 SQL 中的行内注释（`--`），根据注释内容决定是否替换前面的硬编码值。

**识别控件 ID 前缀**：`HIDE_`、`LBL_`、`TXT_`、`WXT_`、`SEL_` 等。

**规则 A — 注释以控件 ID 前缀开头**：将硬编码值替换为 `'@控件ID@'`，删除注释。

```
转换前：ILLI.CUSTOMERID = '1000'--SEL_CUSTOMERID_1
转换后：ILLI.CUSTOMERID = '@SEL_CUSTOMERID_1@'

转换前：ILLI.LOCATIONID = 'M-02-01-02'--TXT_FMLOCATION_1，库位ID
转换后：ILLI.LOCATIONID = '@TXT_FMLOCATION_1@'
```

> 注释中控件 ID 之后的中文描述（如"，库位ID"）忽略，只取控件 ID 部分。

**规则 B — 注释不以控件 ID 前缀开头**：保持原样，不替换。

```
转换前：ILA.LOTATT08 = 'Y'--质量检验状态
转换后：ILA.LOTATT08 = 'Y'（保持不变）
```

### 步骤 5：允许为空转换

当注释中包含"允许为空"时，该条件需要特殊处理：

```
转换前：US.ZONEGROUP = 'LC'--TXT_AREA_15，允许为空
转换后：(US.ZONEGROUP = '@TXT_AREA_15#ALLOW_EMPTY#@')
```

转换要点：
- 整个条件用圆括号 `(...)` 包裹
- 参数格式为 `'@参数名#ALLOW_EMPTY#@'`
- 这告诉 FLUX 平台：当该控件值为空时，此条件不参与 SQL 拼接

### 步骤 6：子查询外层处理

如果最外层是 `SELECT ... FROM (子查询) 别名` 且没有 WHERE 子句，在末尾追加 `WHERE 1=1`。

```
转换前：
SELECT COUNT(1) AS @HIDE_INVCOUNT_1@
FROM ( ... ) A;

转换后：
SELECT COUNT(1) AS @HIDE_INVCOUNT_1@
FROM ( ... ) A
WHERE 1=1
```

### 步骤 7：收尾格式化

1. **删除末尾分号**：FLUX RF 端不要求分号
2. **FROM-WHERE / JOIN-ON 配对检查**：确保每个 FROM 有对应的 WHERE，每个 JOIN 有对应的 ON
3. **GROUP BY 补充**：如果子查询内部的 SELECT 增加了 ORGANIZATIONID 列（步骤 2 删除 WHERE 条件后可能需要在子查询中保留该列用于 GROUP BY），检查并补充

## 转换示例

### 示例 1：列表查询（无别名 → LIST_VIEW）

输入：
```sql
SELECT BZ.ZONEGROUPDESCR,
       US.KEEPER
FROM UDF_STOREKEEPER US
LEFT JOIN BAS_ZONEGROUP BZ ON BZ.ORGANIZATIONID = US.ORGANIZATIONID AND BZ.WAREHOUSEID = US.WAREHOUSEID AND BZ.ZONEGROUP = US.ZONEGROUP
WHERE US.ORGANIZATIONID = 'ND'
  AND US.WAREHOUSEID = 'NDCZ'
  AND US.ZONEGROUP = 'LC'--TXT_AREA_15，允许为空
  AND US.ACTIVEFLAG = 'Y'
ORDER BY US.SHOWSEQUENCE;
```

输出：
```sql
SELECT BZ.ZONEGROUPDESCR AS @LIST_VIEW@,
       US.KEEPER         AS @LIST_VIEW@
FROM UDF_STOREKEEPER US
LEFT JOIN BAS_ZONEGROUP BZ ON BZ.WAREHOUSEID = US.WAREHOUSEID AND BZ.ZONEGROUP = US.ZONEGROUP
WHERE US.WAREHOUSEID = '#WAREHOUSEID#'
  AND (US.ZONEGROUP = '@TXT_AREA_15#ALLOW_EMPTY#@')
  AND US.ACTIVEFLAG = 'Y'
ORDER BY US.SHOWSEQUENCE
```

### 示例 2：带隐藏字段和控件参数的查询

输入：
```sql
SELECT ILLI.LOCATIONID AS HIDE_LOCATIONID_1,
       ILLI.TRACEID    AS HIDE_TRACEID_1,
       ILLI.SKU        AS HIDE_SKU_1,
       ILLI.CUSTOMERID AS HIDE_CUSTOMERID_1,
       BS.SKUDESCR1    AS LBL_SKUDESCR_1,
       ILA.LOTATT04    AS LBL_LOTATT04_1,
       ILA.LOTATT05    AS LBL_LOTATT05_1,
       ILA.LOTATT06    AS LBL_LOTATT06_1,
       ILA.LOTATT07    AS LBL_LOTATT07_1,
       ILA.LOTATT01    AS LBL_LOTATT01_1,
       ILA.LOTATT08    AS LBL_LOTATT08_1
FROM INV_LOT_LOC_ID ILLI
    LEFT JOIN BAS_SKU BS ON BS.ORGANIZATIONID = ILLI.ORGANIZATIONID AND BS.CUSTOMERID = ILLI.CUSTOMERID AND BS.SKU = ILLI.SKU
    LEFT JOIN INV_LOT_ATT ILA ON ILA.ORGANIZATIONID = ILLI.ORGANIZATIONID AND ILA.LOTNUM = ILLI.LOTNUM
WHERE ILLI.ORGANIZATIONID = 'ND'
  AND ILLI.WAREHOUSEID = 'NDCZ'
  AND ILLI.CUSTOMERID = '1000'--SEL_CUSTOMERID_1
  AND ILLI.LOCATIONID = 'M-02-01-02'--TXT_FMLOCATION_1
  AND ILA.LOTATT08 = 'Y'
  AND ILLI.TRACEID = '00710'--TXT_FMTRACEID_1
  AND ILLI.QTY - ILLI.QTYALLOCATED - ILLI.QTYMVOUT - ILLI.QTYONHOLD - ILLI.QTYRPOUT > 0;
```

输出：
```sql
SELECT ILLI.LOCATIONID AS @HIDE_LOCATIONID_1@,
       ILLI.TRACEID    AS @HIDE_TRACEID_1@,
       ILLI.SKU        AS @HIDE_SKU_1@,
       ILLI.CUSTOMERID AS @HIDE_CUSTOMERID_1@,
       BS.SKUDESCR1    AS @LBL_SKUDESCR_1@,
       ILA.LOTATT04    AS @LBL_LOTATT04_1@,
       ILA.LOTATT05    AS @LBL_LOTATT05_1@,
       ILA.LOTATT06    AS @LBL_LOTATT06_1@,
       ILA.LOTATT07    AS @LBL_LOTATT07_1@,
       ILA.LOTATT01    AS @LBL_LOTATT01_1@,
       ILA.LOTATT08    AS @LBL_LOTATT08_1@
FROM INV_LOT_LOC_ID ILLI
    LEFT JOIN BAS_SKU BS ON BS.CUSTOMERID = ILLI.CUSTOMERID AND BS.SKU = ILLI.SKU
    LEFT JOIN INV_LOT_ATT ILA ON ILA.LOTNUM = ILLI.LOTNUM
WHERE ILLI.WAREHOUSEID = '#WAREHOUSEID#'
  AND ILLI.CUSTOMERID = '@SEL_CUSTOMERID_1@'
  AND ILLI.LOCATIONID = '@TXT_FMLOCATION_1@'
  AND ILA.LOTATT08 = 'Y'
  AND ILLI.TRACEID = '@TXT_FMTRACEID_1@'
  AND ILLI.QTY - ILLI.QTYALLOCATED - ILLI.QTYMVOUT - ILLI.QTYONHOLD - ILLI.QTYRPOUT > 0
```

### 示例 3：子查询 + COUNT

输入：
```sql
SELECT COUNT(1) AS HIDE_INVCOUNT_1
FROM (
    SELECT ILLI.LOCATIONID, ILLI.TRACEID, ILLI.SKU, ILLI.CUSTOMERID
    FROM INV_LOT_LOC_ID ILLI
    LEFT JOIN BAS_SKU BS ON BS.ORGANIZATIONID = ILLI.ORGANIZATIONID AND BS.CUSTOMERID = ILLI.CUSTOMERID AND BS.SKU = ILLI.SKU
    LEFT JOIN INV_LOT_ATT ILA ON ILA.ORGANIZATIONID = ILLI.ORGANIZATIONID AND ILA.LOTNUM = ILLI.LOTNUM
    WHERE ILLI.ORGANIZATIONID = 'ND'
        AND ILLI.WAREHOUSEID = 'NDCZ'
        AND ILLI.CUSTOMERID = '1000'--SEL_CUSTOMERID_1
        AND ILLI.LOCATIONID = 'M-02-01-02'--TXT_FMLOCATION_1
        AND ILA.LOTATT08 = 'Y'
        AND ILLI.TRACEID = '00710'--TXT_FMTRACEID_1
        AND ILLI.QTY - ILLI.QTYALLOCATED - ILLI.QTYMVOUT - ILLI.QTYONHOLD - ILLI.QTYRPOUT > 0
    GROUP BY ILLI.LOCATIONID, ILLI.TRACEID, ILLI.SKU, ILLI.CUSTOMERID, BS.SKUDESCR1, ILA.LOTATT01, ILA.LOTATT04, ILA.LOTATT05, ILA.LOTATT06, ILA.LOTATT07, ILA.LOTATT08
     ) A;
```

输出：
```sql
SELECT COUNT(1) AS @HIDE_INVCOUNT_1@
FROM (
    SELECT ILLI.ORGANIZATIONID, ILLI.LOCATIONID, ILLI.TRACEID, ILLI.SKU, ILLI.CUSTOMERID
    FROM INV_LOT_LOC_ID ILLI
    LEFT JOIN BAS_SKU BS ON BS.CUSTOMERID = ILLI.CUSTOMERID AND BS.SKU = ILLI.SKU
    LEFT JOIN INV_LOT_ATT ILA ON ILA.LOTNUM = ILLI.LOTNUM
    WHERE ILLI.WAREHOUSEID = '#WAREHOUSEID#'
        AND ILLI.CUSTOMERID = '@SEL_CUSTOMERID_1@'
        AND ILLI.LOCATIONID = '@TXT_FMLOCATION_1@'
        AND ILA.LOTATT08 = 'Y'
        AND ILLI.TRACEID = '@TXT_FMTRACEID_1@'
        AND ILLI.QTY - ILLI.QTYALLOCATED - ILLI.QTYMVOUT - ILLI.QTYONHOLD - ILLI.QTYRPOUT > 0
    GROUP BY ILLI.ORGANIZATIONID, ILLI.LOCATIONID, ILLI.TRACEID, ILLI.SKU, ILLI.CUSTOMERID, BS.SKUDESCR1, ILA.LOTATT01, ILA.LOTATT04, ILA.LOTATT05, ILA.LOTATT06, ILA.LOTATT07, ILA.LOTATT08
) A
WHERE 1=1
```

> 示例 3 的特殊点：子查询中删除了 ORGANIZATIONID 的 WHERE 条件，但 GROUP BY 中需要补充 `ILLI.ORGANIZATIONID` 列，以保持子查询内部数据的完整性。同时外层追加了 `WHERE 1=1`。

## 输出要求

1. **只输出转换后的 SQL**，用 SQL 代码块包裹
2. 如果 SQL 有多条语句，逐条转换
3. 转换完成后，列出关键变更摘要（如：删除了哪些 ORGANIZATIONID 条件、替换了哪些系统常量、转换了哪些控件参数）
4. 如果用户的 SQL 存在无法确定的模糊情况（如注释格式不符合预期），主动询问用户
